🌏让你的浏览器好用100倍

发表于2021-08-22|更新于2021-08-22
|字数总计:859|阅读时长:2分钟|阅读量:

前言

  1. 日常情况下，我们的”下载”都是在浏览器上完成的，为了有更快的下载速度，我们也会使用 IDM、迅雷等多线程下载工具来接管浏览器下载。

  2. 下载工具会比浏览器自带的下载器下载速度更快，主要是因为下载工具采用多线程下载，而浏览器一般是单线程下载。

开启浏览器多线程下载

可能你还不知道，其实谷歌内核的浏览器如：Chrome、edge 他们自带的下载器都隐藏着多线程下载的功能，只是这个多线程下载默认是关闭的，需要我们手动开启！

  1. Chrome 浏览器只需要将下面的地址复制到地址栏 — 回车 — 然后将 黄色框选的 Parallel downloading 默认的 Default 改成 Enabled 即可，改完点击右下角的重启浏览器即可。

chrome://flags/#enable-parallel-downloading

图片

如果你的用的是新版谷歌内容的 edge 浏览器，则在浏览器地址栏输入下面的链接，进行相同的修改。

edge://flags/#enable-parallel-downloading

改完之后我们的浏览器就拥有了多线程的下载功能，直接使用使用自带浏览器同样也能轻松让下载速度跑满带宽。

当然只是提高下载速度，还不足以让我卸载 IDM，因为浏览器自带的下载器还缺乏对下载文件的管理功能，批量下载，查看下载进度 都不太方便。不过今天小帮给你推荐的这款浏览器插件可以完美解决。

Chrono 下载管理器
Chrono 下载管理器 是专为 Chrome 浏览器设计的全功能下载管理器插件，他直接无缝接管 Google Chrome 中的下载，让你无需安装其他第三方下载工具，就能享受到 IDM 和迅雷这类下载工具的下载管理功能。

图片

你可以直接使用快捷 Ctrl + J 打开 Chrono 下载管理器 ，然后在 Chrono 管理器中对已经下载过的图片、音频、视频等文件格式直接预览，无需打开文件。

图片

当下载任务完成后，它会在电脑桌面右下角 弹窗下载完成的消息通知同时会伴有下载完成的声音提醒。

图片

Chrono 资源嗅探功能
对于 IDM 我们都知道他们的资源嗅探功能很强大，网页上的大部分视频音频都可以直接使用 idm 嗅探下载。

而 Chrono 同样支持资源嗅探功能，它能检测网页上的所有链接、图片、音频和视频，你还可以根据链接的文件类型或正则表达式来筛选你要下载的地址！

图片

网页上的图片、视频、音频 他都可以很轻松的嗅探出来并且支持一键批量下载，当然有些加密的视频可能没办法下载，这时候我们就只能另辟奇径了。

总的来说 Chrono 让浏览器的下载能力提升了的一个大档次，不需要单独安装下载工具，在浏览器内就可以完成所有下载管理功能。配合上开启浏览器的多线程下载功能，真的不需要安装 IDM 了，主要是完全免费！
